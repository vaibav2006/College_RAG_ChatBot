# MEPCO College Static RAG Chatbot

This is a GitHub Pages compatible browser-side retrieval chatbot.

## Important
GitHub Pages is static hosting, so this version does not run Python, FAISS, LangChain, or Qwen.
Instead, the PDF text is extracted during preparation and the browser performs keyword-based retrieval over those document chunks.

Sources:
- Institutional Development Plan 2024–2029
- Code of Conduct Handbook

## Run
Open `index.html` locally or publish the repository with GitHub Pages.

## GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
